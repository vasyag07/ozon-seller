## План и принятые контракты
1. Снять исходный результат полного набора тестов; добавить тесты до реализации и подтвердить отсутствие методов.
2. Добавить Service/V2/WarehouseService::list(array $requestData = []): array. Стандартные limit=10, cursor=''; входные значения переопределяют стандартные. Дополнительный warehouse_ids, не более 200. Локальная проверка limit 1–200 без обрезки данных. Возврат всего ответа warehouses/cursor/has_next; одна страница.
3. Добавить V3/Posting/FbsService::packageLabelCreate(array $postingNumbers): array: POST /v3/posting/fbs/package-label/create, posting_numbers из 1–1000 непустых строк, возврат полного ответа tasks. Не выбирать первое задание.
4. Добавить V2/Posting/FbsService::packageLabelGet(int $taskId): array: POST /v2/posting/fbs/package-label/get, возврат всего JSON status/error/file_url, без скачивания и ожидания.
5. Старые Warehouse V1 list и V2 packageLabel сохранить и пометить @deprecated; не менять бинарный контракт старого packageLabel.
6. Добавить руководство перехода; выполнить целевые/общие тесты, синтаксис, проверку diff и итоговый самоконтроль.

## Приёмка и проверки
Тесты с подставным HTTP-клиентом без ключей/сети: адреса, POST, JSON, граничные limit и количество отправлений, ошибки HTTP, поля пагинации, несколько задач, состояния и ошибки при HTTP 200. Не пересылать API-заголовки на адрес файла: SDK его вообще не запрашивает.
CI: php -d zend.assertions=1 vendor/bin/phpunit --exclude-group=e2e --coverage-clover=/private/tmp/ozon-warehouse-label-coverage.xml. В Composer нет команд анализа/стиля. PHP >=7.1 сохраняется; доступный PHP 8.5, выполнение на 7.4 не обещать без соответствующего интерпретатора.
Публикация, push, записи MR/Redmine, БД и развёртывание требуют отдельного согласования и не выполняются.

## Выполненные изменения
- Новый Service/V2/WarehouseService: list с $default, array_merge и ArrayHelper::pick, проверками limit/warehouse_ids, без автоматического обхода. Все поля страницы сохранены.
- V3/Posting/FbsService::packageLabelCreate сохраняет все tasks, проверяет 1–1000 непустых строк; array_values обеспечивает JSON-массив даже для входного массива с другими ключами.
- V2/Posting/FbsService::packageLabelGet сохраняет весь JSON, включая error при HTTP 200 и status.unprinted_postings. Ни скачивания, ни ожидания/повторных запросов нет.
- Старые методы сохранены, изменены только их комментарии @deprecated. Синхронный packageLabel по-прежнему возвращает строку PDF.
- README: пример обхода складов с ограничением страниц и проверкой курсора; создание всех задач этикеток, получение состояния и отдельный шаг скачивания без API-заголовков. Рекомендация 45–60 секунд описана без блокирующей задержки SDK.
